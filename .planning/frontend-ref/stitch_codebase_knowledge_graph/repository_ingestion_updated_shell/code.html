Explain the authentication flow in the current codebase. Specifically, how is the JWT token validated during API requests?
smart_toy
The authentication flow relies on a middleware function that intercepts incoming requests. It extracts the Bearer token from the Authorization header and verifies it using the public key retrieved from the JWKS endpoint.

src/middleware/jwt.ts 
export const verifyToken = async (req: Request, res: Response, next: NextFunction) => {
    const authHeader = req.headers.authorization;
    if (!authHeader || !authHeader.startsWith('Bearer ')) {
        return res.status(401).json({ error: 'Unauthorized' });
    }

    const token = authHeader.split(' ')[1];
    try {
        const decoded = await jwtService.verify(token);
        req.user = decoded;
        next();
    } catch (err) {
        /* Token validation failed */
        return res.status(403).json({ error: 'Forbidden' });
    }
};
If validation is successful, the decoded payload is attached to the req.user object for downstream handlers.
