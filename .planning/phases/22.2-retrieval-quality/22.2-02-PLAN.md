     changed is noise. miniflux measures that noise directly: its chunk set
     is identical (equal digests). Noise is reported as noise.

       something the census or the tests show, such as a changed breadcrumb.
     - A lower rank on its own is not "wrong" (QD1).

     changes to recover a number.

**Lessons that apply here** (review checklist):
- **A chunker that raises on every file must never empty an index** (PR #58,
  review B's M3).
  - `_parse` skips raising files and `_write_results` replaces the whole set.
    So a chunker bug that raised on every file would complete the job
    `synced` with nothing indexed.
  - The guard 22-05 adds after that review stops it: when
    `files_indexable > 0` and every file raised, the job fails and the old
    chunks stay.
  - At planning time (2026-09-29, PR #58's head `12b5934`) that guard is not
    yet in the PR. This plan starts only after #58 merges with it.
  - Task 1 names its test, and every task's verify runs it.
- **The census catches what that guard cannot.** The chunker's catch-all turns
  most failures into a silent fallback, not a raise. 22.2-01's census counts
  fallbacks by cause, per corpus, and "raised" must stay 0.
- **Assert the parse, not only the names.** Every TS, TSX and JS fixture
  asserts `has_error` is false with the grammar the parser chose. That is the
  assertion whose absence hid the bug.
- **Breadcrumbs are what symbol scoring reads** (`scoring.py:28-29`).
  - For Python and Go, the multiset of `(file_path, chunk_type, breadcrumb)`
    must be identical before and after. Only spans and text move.
  - Each decorator test asserts the breadcrumb.
- **A test that reads no log record cannot catch a logging bug.** The
  truncation warning is asserted from captured logs.
  - It names the path and the breadcrumb, **never the content**. A sentinel
    in the content must not appear in any log.
- **Every progress report carries the whole cumulative dict** (22-05).
  `chunks_truncated` joins it, and the test reads the **completed** row.
- **Commit before mutating, and prove each mutation landed by reading
  bytes.**

  - never print `OPENAI_API_KEY`: check it by its length.
