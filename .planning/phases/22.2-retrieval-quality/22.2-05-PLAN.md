**Facts that shape the tasks** (read on `main` at `cd9dd12`, and on PR #67's
branch at `67af4f9`):

  run prompt cannot change them.**

    module-level `const` … bound to an arrow function", "an interface, a type

    `ResponseHandler.isCloudflareChallenge`), Python methods and nested
    functions are not described.
  - **The avoid-list counts toward the spread** ("Count each pair on the
    avoid-list toward its path's package", same file, "The avoid-list"). Here

**Lessons that apply here:**
- **The commit order is the evidence:** rules (on `main`), then A, B, C,
  then the merge, then the first `shape-model` ingest. A question is never
  edited after a result for it exists.

  symbol spelled differently from the chunker's name may be corrected,
  recorded before and after. A question that echoes its symbol goes back to
  its writer to rephrase.

- **A check that passes vacuously proves nothing** (22.2-03's
