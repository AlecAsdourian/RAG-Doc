### The audit (`audit_writer.py`, `writer-audit.txt`)

The audit voids a whole batch on any of:
- a path outside the checkout, after normalisation and with links followed;
- a Grep or Glob with no path;
- a relative path;
- a `..` segment;
- an absolute Glob pattern or Grep `glob` filter;
- a search over a directory holding a link out of the checkout;
- a tool other than the three plus the hand-back;
- another agent type.

**Its tests:** 62 passed, 1 skipped. The skip is a true OS symlink, which this account cannot create; a junction covers the same case. **The mutation checks:** five mutants, each proven by bytes to have landed and to have been restored, each failing the tests written for it (`mutate_handback.py`, `mutate_turns.py`, `audit-writer-tests.txt`).
