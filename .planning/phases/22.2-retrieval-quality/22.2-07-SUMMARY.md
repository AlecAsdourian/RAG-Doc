## 1. The rule schema, and M2 as JSON

`decide.py` checks every rule on load (`schema_problems`); any failure is refusal 8.

| key | meaning |
|---|---|
| `rule` | the id (`"M2"`, `"chunk-shape"`) |
| `protocol` | the `.md` beside the JSON; it must exist there |
| `set`, `corpora`, `top_k` | the decision set, the corpora pooled, the cut |
| `metric` | must be `mrr@<top_k>` |
| `variable` | `embedding_model` or `chunker` |
| `arms` | record prefix → declared value: a model name, or `{chunker_version, chunker_variant}` (either or both) |
| `pair` | `{baseline, candidate}`, for a rule applied on its own |
| `after` + `arms_by_verdict` | instead of `pair`: the rule applied first, and the pair each of its verdicts (`ADOPT`, `REJECT`) selects |
| `clauses` | `[{id, level: file\|symbol, scope: pooled\|each_corpus, min_delta}]`; holds when Δ ≥ `min_delta` − `allowance` |
| `allowance` | in [0, 1e-6); M2's is 1e-9 |
| `description` | optional prose |

Unknown keys are refused, so a clause type the schema lacks cannot be ignored silently: a rule
that needs one extends the schema, with tests, in its own plan (QD7, QD9).

`embedding-model-rule.json` (M2, exactly as `3cd1d71`/`afa50b2` state it):
- set `shape-model`; corpora miniflux, mealie, linkwarden; `top_k` 5, `mrr@5`; variable
  `embedding_model`; arms `current-ada`, `candidate-ada` (ada-002), `current-3small`,
  `candidate-3small` (3-small);
- `after: "chunk-shape"`: `ADOPT` → `candidate-ada` vs `candidate-3small`; `REJECT` →
  `current-ada` vs `current-3small`;
- clauses: 1 symbol pooled 0.03; 2 file pooled 0; 3 file each_corpus −0.11; allowance 1e-9.

`TestM2EncodesItsProtocol` reads the protocol's Rule section (each numbered clause's level,
scope and number), its Precision section (the three "is Δ ≥ …" thresholds, evaluated, and the
1e-9 allowance), its Test set (the corpora), Candidate, and Arms sections, and asserts they are
the JSON's.

**The verdicts:** `holds()` is tested on M2's committed numbers at exactly `min_delta − 1e-9`
(holds) and 2e-9 past it (fails), per clause. End to end, each clause is driven by records to
exactly its bar (+0.03 = 1.35/45; 0; −0.11 = −1.65/15: adopts) and one rank step past it
(rejects). **The rule order:** `TestTheRuleOrder` builds the candidate and current M2 pairs to
give opposite verdicts, and shows that chunk-shape `ADOPT` judges the `candidate-*` arms and
`REJECT` the `current-*` arms.

**It prints** per rule: per corpus and pooled, MRR, recall and rank-1 at 5 for file and symbol;
MRR@20 from the `boosted` list joined to its legs by `chunk_id` (or "unavailable" below 20
ranked results); the per-question table; answers tied with the cut at 2e-6 (reported only);
each clause with its Δ, bar and result; `VERDICT: ADOPT|REJECT (rule)`. Exit 0 when every rule
adopted, 1 when any rejected. `decide-fixture-run.txt` holds three real CLI runs on the test
fixtures (exit 1, 0 and 2).

**`vector_sha256` moved to `chunk_digest.py`,** one definition; the harness keeps the name as
an alias. `decide.py` checks cached vectors with the same function the harness recorded with.

## 9. Deviations

1. **The order check is stricter than its words.** The plan names "the commit that added the
   rule's JSON"; `decide.py` requires *every* commit that changed it to precede the questions, so
   a rule edited after its questions is refused too. A merge commit counts only when it differs
   from every parent, so QD12's protocol merge passes.
2. **Refusal 5 also covers** an arm's header against the rule (set, `top_k`, corpus, the declared
   variable), every pair an after-rule could select, and, for a chunk comparison, equal
   query-vector hashes per question.
3. **Refusal 1 also refuses** a symbol clause over a question naming no symbol, since the
   protocol's symbol MRR is "over the same 45".
4. **`vector_sha256` moved** from the harness to `chunk_digest.py`, so the judge does not carry
   a copy (the checklist's "helper carrying its own copy" lesson).
5. **The independence check treats a symbol-less question as targeting its file,** which is
   stricter than `(path, symbol)` read literally; no committed question lacks a symbol.
6. **`decide.py` buffers its output** and prints nothing but the refusal when it refuses.
