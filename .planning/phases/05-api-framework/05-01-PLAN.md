    File: services/backend/pkg/api/router.go

    Implement:
    1. NewRouter() function that returns chi.Router
    2. Middleware chain in correct order:
       - middleware.RequestID (first - generates request ID)
       - httplog.RequestLogger (logs start/end with request ID)
       - middleware.Recoverer (catches panics, logs them)
       - middleware.RealIP (handles X-Forwarded-For)
    3. Public routes group (no auth):
       - GET /health
       - POST /webhooks/supabase
    4. Protected routes group (with auth):
       - Use existing TenantMiddleware from pkg/auth
       - Mount at /api/* for search/chat endpoints (handlers added in later plans)

    Use httplog.NewLogger with options:
    - JSON: true (for production log parsing)
    - LogLevel: slog.LevelInfo
    - Concise: true
    - RequestHeaders: true (for debugging)

    Do NOT use middleware.Timeout on the main router — SSE endpoints need no timeout.
    Timeout will be applied selectively to non-streaming routes.

    Import existing auth middleware from pkg/auth.
  </action>
  <verify>go build ./... succeeds, no import errors</verify>
  <done>router.go created with Chi router, middleware chain configured, public/protected route groups defined</done>
