  <action>
    Create FastAPI application in services/workers/api/ directory.

    **api/models.py** - Pydantic models for request/response:
    ```python
    from pydantic import BaseModel, Field
    from typing import List, Optional
    from uuid import UUID

    class SearchRequest(BaseModel):
        query: str = Field(..., min_length=1, max_length=1000)
        repository_id: UUID
        top_k: int = Field(default=10, ge=1, le=50)

    class ChunkResult(BaseModel):
        chunk_id: str
        content: str
        content_preview: str
        file_path: str
        start_line: int
        end_line: int
        breadcrumb: Optional[str]
        score: float

    class SearchResponse(BaseModel):
        results: List[ChunkResult]
        query_id: UUID
        total_results: int

    class ChatRequest(BaseModel):
        query: str = Field(..., min_length=1, max_length=2000)
        repository_id: UUID
        top_k: int = Field(default=5, ge=1, le=20)

    class ChatResponse(BaseModel):
        answer: str
        sources: List[dict]
        query_id: UUID
        cost: float
        tokens_in: int
        tokens_out: int
        cache_hit: bool
    ```

    **api/routes.py** - Endpoint handlers:
    - POST /search - calls QueryEngine.query(), returns SearchResponse
    - POST /chat - calls AnswerGenerator.generate(), returns ChatResponse
    - GET /health - returns {"status": "ok", "service": "rag-api"}

    **api/main.py** - FastAPI app setup:
    - Create FastAPI app with title "RAG API"
    - Initialize QueryEngine and AnswerGenerator on startup (lifespan)
    - Load config from environment variables:
      - DATABASE_URL, QDRANT_URL, OPENAI_API_KEY, REDIS_URL (for semantic cache)
    - Include routes from routes.py

    Use dependency injection for QueryEngine/AnswerGenerator (store on app.state).
  </action>

<task type="auto">
  <name>Task 3: Add FastAPI service to Docker Compose</name>
  <files>services/workers/Dockerfile.api, docker-compose.yml</files>
  <action>
    Create separate Dockerfile for the FastAPI API service (distinct from worker processes).

    **services/workers/Dockerfile.api:**
    ```dockerfile
    FROM python:3.11-slim

    WORKDIR /app

    # Install dependencies
    COPY requirements.txt .
    RUN pip install --no-cache-dir -r requirements.txt

    # Copy application code
    COPY . .

    # Run FastAPI with uvicorn
    CMD ["uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8000"]
    ```

    **Update docker-compose.yml:**
    Add new service `rag-api`:
    ```yaml
    rag-api:
      build:
        context: ./services/workers
        dockerfile: Dockerfile.api
      ports:
        - "8001:8000"  # Expose on 8001 to avoid conflicts
      environment:
        - DATABASE_URL=${DATABASE_URL}
        - QDRANT_URL=http://qdrant:6333
        - OPENAI_API_KEY=${OPENAI_API_KEY}
        - REDIS_URL=redis://redis:6379
      depends_on:
        - postgres
        - qdrant
        - redis
      networks:
        - backend
    ```

    Add RAG_SERVICE_URL environment variable to backend service:
    ```yaml
    backend:
      environment:
        - RAG_SERVICE_URL=http://rag-api:8000
    ```
  </action>
