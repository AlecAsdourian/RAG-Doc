## Components Built

**Plan 1**: FTSRetriever - Postgres full-text search
**Plan 2**: VectorRetriever - Qdrant semantic search, QueryParser - exact-match detection
**Plan 3**: RRFFusion - Reciprocal rank fusion with overlap boost
**Plan 4**: MetadataBooster - Chunk-type, path, and exact-match boosts

## Integration Flow

1. Parse query (QueryParser) → extract quoted terms, identifiers
2. Run FTS and vector searches in parallel (both return top 50)
3. Fuse results with RRF (combine + overlap boost)
4. Apply metadata boosts (chunk-type, path, exact-match, noise penalties)
5. Sort by final score, return top 5-10 chunks

  <action>
Create QueryEngine class that orchestrates the full pipeline.

Class: QueryEngine
- __init__(self, postgres_conn: str, qdrant_url: str, openai_api_key: str)
  - Initialize all components: FTSRetriever, VectorRetriever, QueryParser, RRFFusion, MetadataBooster
  - Load boost config from env vars if present (BOOST_DOCS, BOOST_ENTRYPOINT, PENALTY_VENDOR, etc.)

- query(self, query_text: str, repository_id: UUID, top_k: int = 5, run_id: UUID = None) -> Dict

Implementation:
1. Start timer for duration tracking
2. Parse query with QueryParser → get quoted_terms, identifiers
3. Run FTS and vector retrievals in parallel (use threading or asyncio):
   - fts_results = fts_retriever.search(query_text, repository_id, limit=50, run_id=run_id)
   - vector_results = vector_retriever.search(query_text, repository_id, limit=50, run_id=run_id)
4. Fuse results with RRFFusion:
   - fused = rrf_fusion.fuse({"fts": fts_results, "vector": vector_results})
5. Apply metadata boosts:
   - boosted = metadata_booster.boost(fused, parsed_query)
6. Sort by boosted_score descending, take top_k (default 5)
7. For each result, fetch full metadata from Postgres:
   - Query chunks table to get complete metadata, breadcrumb, content preview (first 200 chars)
   - Query ingestion_runs to get commit_sha, completed_at for provenance
8. Build response dict with results, metadata (counts, duration)
9. Return response

Parallel execution: Use concurrent.futures.ThreadPoolExecutor for FTS + vector:
```python
import concurrent.futures

with concurrent.futures.ThreadPoolExecutor(max_workers=2) as executor:
    fts_future = executor.submit(fts_retriever.search, ...)
    vector_future = executor.submit(vector_retriever.search, ...)
    fts_results = fts_future.result()
    vector_results = vector_future.result()
```

Error handling: Log errors but return partial results if one retriever fails.

Update workers/retrieval/__init__.py to export QueryEngine.
