## Boosting Strategy from CONTEXT.md

**Chunk-type boosts** (configurable multipliers):
- docs/entrypoints/middleware/config: 1.5x
- helpers: 1.0x (neutral)
- tests: 0.8x (slight penalty)

**Path/scope boosts**:
- auth/, security/, middleware/: 1.2x if query mentions related terms
- Match on breadcrumb (qualified names): 1.3x

**Exact-match boosts**:
- Quoted strings appear in content: 1.4x
- Identifiers (from QueryParser) appear in content or breadcrumb: 1.3x

**Noise penalties**:
- Vendor/generated paths: 0.3x
- Patterns: */node_modules/*, */vendor/*, */dist/*, */build/*, *.lock, *-lock.json, */migrations/*, */__pycache__/*, */.git/*

**Final score**: base_score * boost_multiplier

## Example

Chunk: {chunk_type: "function", file_path: "src/auth/login.py", breadcrumb: "AuthService.login", rrf_score: 0.5}
Query parsed: {quoted_terms: ["AuthError"], identifiers: ["AuthService"]}

Boosts applied:
- Base: 0.5
- Chunk type "function" (neutral): 1.0x
- Path contains "auth/": 1.2x (if query relevant)
- Breadcrumb matches identifier "AuthService": 1.3x
- Combined: 0.5 * 1.0 * 1.2 * 1.3 = 0.78

  <behavior>
Given a list of chunks with base scores and metadata, apply boost/penalty multipliers based on rules.

Test cases:

1. **No boosts**: Chunk with neutral metadata → score unchanged
2. **Chunk-type boost**: chunk_type="docs" → 1.5x multiplier
3. **Chunk-type penalty**: chunk_type="test" → 0.8x multiplier
4. **Path boost**: file_path contains "auth/" and query has "auth" → 1.2x
5. **Breadcrumb exact match**: breadcrumb matches identifier from query → 1.3x
6. **Quoted term match**: quoted term appears in content → 1.4x
7. **Noise penalty**: file_path="node_modules/pkg/index.js" → 0.3x
8. **Combined boosts**: Multiple boosts multiply together
9. **Custom weights**: Override default boost values via config

Expected behavior:
- Input: List[Dict] (chunks with rrf_score, metadata), ParsedQuery (from QueryParser)
- Output: List[Dict] (chunks with boosted_score)
- Boosts multiply base score
- Configurable boost weights (env vars or constructor params)
  </behavior>
  <implementation>
Class: MetadataBooster
- __init__(self, config: Dict = None) - Load boost weights from config or defaults
- boost(self, chunks: List[Dict], parsed_query: Dict) -> List[Dict]

Default weights (can override via config):
```python
{
  "chunk_type_boosts": {
    "docs": 1.5,
    "file_summary": 1.4,
    "class_summary": 1.3,
    "function": 1.0,
    "class": 1.0,
    "test": 0.8,
  },
  "path_boost": 1.2,
  "breadcrumb_match_boost": 1.3,
  "quoted_match_boost": 1.4,
  "identifier_match_boost": 1.3,
  "noise_penalty": 0.3,
}
```

Noise patterns (regex):
```python
NOISE_PATTERNS = [
  r'.*/node_modules/.*',
  r'.*/vendor/.*',
  r'.*/dist/.*',
  r'.*/build/.*',
  r'.*\.lock$',
  r'.*-lock\.json$',
  r'.*/migrations/.*',
  r'.*/__pycache__/.*',
  r'.*/.git/.*',
]
```

Algorithm:
1. For each chunk:
   - Start with multiplier = 1.0
   - Apply chunk_type boost if in config
   - Check file_path for noise patterns → apply penalty
   - Check breadcrumb for identifier matches → apply boost
   - Check content for quoted term matches → apply boost
   - Check content for identifier matches → apply boost
   - Calculate boosted_score = rrf_score * multiplier
   - Add multiplier to chunk dict for transparency
2. Return chunks with boosted_score

Handle missing fields gracefully (default to neutral if metadata missing).
