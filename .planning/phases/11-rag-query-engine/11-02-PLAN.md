<task type="auto">
  <name>Task 2: Implement query parser for exact-match detection</name>
  <files>services/workers/workers/retrieval/query_parser.py</files>
  <action>
Create query parser using regex to detect exact-match terms for boosting.

Class: QueryParser
- parse(self, query: str) -> Dict[str, Any]

Return dict with:
- "raw_query": str - Original query
- "quoted_terms": List[str] - Terms in "quotes" or 'quotes'
- "identifiers": List[str] - CamelCase, snake_case, PascalCase patterns
- "clean_query": str - Query with quoted terms removed (for general search)

Regex patterns:
1. Quoted strings: r'"([^"]+)"|\'([^\']+)\'' - Captures content between quotes
2. PascalCase: r'\b[A-Z][a-zA-Z0-9]*(?:[A-Z][a-zA-Z0-9]*)+\b' - e.g., AuthService, JWTValidator
3. camelCase: r'\b[a-z]+[A-Z][a-zA-Z0-9]*\b' - e.g., getUserById, isValid
4. snake_case: r'\b[a-z_][a-z0-9_]{2,}\b' - e.g., get_user_by_id, is_valid (min 3 chars to avoid noise)

Example:
  Input: 'How does "AuthError" work in UserService?'
  Output: {
    "raw_query": 'How does "AuthError" work in UserService?',
    "quoted_terms": ["AuthError"],
    "identifiers": ["UserService"],
    "clean_query": "How does work in UserService?"
  }

Keep it simple - no complex query operators (AND, OR, NOT out of scope per CONTEXT.md).

Update workers/retrieval/__init__.py to export QueryParser.
  </action>
