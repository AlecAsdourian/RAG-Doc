  <action>
Create FTS retriever that queries Postgres using ts_query and ts_rank.

Class: FTSRetriever
- __init__(self, postgres_conn_string) - Initialize with DB connection
- search(self, query: str, repository_id: UUID, limit: int = 50, run_id: UUID = None) -> List[Dict]

Implementation:
1. Convert query to tsquery format (use plainto_tsquery for simple conversion, handles spaces/punctuation)
2. Query chunks table: WHERE to_tsvector('english', content) @@ plainto_tsquery('english', %s)
3. Also search breadcrumb field: OR to_tsvector('english', breadcrumb) @@ plainto_tsquery('english', %s)
4. Score using ts_rank_cd (considers proximity): ts_rank_cd(to_tsvector('english', content), plainto_tsquery('english', %s))
5. Filter by repository_id, optionally by ingestion_run_id (if run_id provided)
6. If run_id is None, get latest successful run for repository: SELECT id FROM ingestion_runs WHERE repository_id = %s AND status = 'completed' ORDER BY completed_at DESC LIMIT 1
7. Return results with: chunk_id, file_path, start_line, end_line, breadcrumb, chunk_type, content (first 200 chars), fts_score

Use parameterized queries (no SQL injection). Close cursor after query. Return empty list if no results.

Package __init__.py exports: from .fts_retriever import FTSRetriever
