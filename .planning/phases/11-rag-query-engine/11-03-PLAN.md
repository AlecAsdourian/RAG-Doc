## RRF Algorithm

Standard reciprocal rank fusion formula:
```
score(chunk) = Σ(1 / (k + rank_i)) across retrieval systems
```

Where:
- k = 60 (standard constant, balances contribution of ranks)
- rank_i = position in result list (1-indexed: 1st place = rank 1)
- Σ sums across all systems where chunk appears

Overlap boost is automatic: chunks in both FTS and vector results accumulate scores from both.

## Example

FTS results: [A, B, C]
Vector results: [B, D, A]

Scores (k=60):
- A: 1/(60+1) + 1/(60+3) = 0.0164 + 0.0159 = 0.0323 (in both)
- B: 1/(60+2) + 1/(60+1) = 0.0161 + 0.0164 = 0.0325 (in both, ranked higher)
- C: 1/(60+3) = 0.0159 (FTS only)
- D: 1/(60+2) = 0.0161 (vector only)

Final order: B (0.0325), A (0.0323), D (0.0161), C (0.0159)

Given multiple ranked result lists (from FTS, vector search, etc.), combine into single ranked list using RRF algorithm.

Test cases:

1. **Empty input**: fuse([]) → []
2. **Single result list**: fuse([{"fts": [A, B, C]}]) → [A, B, C] with RRF scores
3. **Two lists, no overlap**: fuse([{"fts": [A, B]}, {"vector": [C, D]}]) → all items ranked by RRF
4. **Two lists with overlap**: fuse([{"fts": [A, B, C]}, {"vector": [B, D, A]}]) → overlap items score higher
5. **Deduplication**: Same chunk_id appears once in final results
6. **Rank calculation**: Verify 1/(k + rank) formula with k=60
7. **Score sorting**: Final results sorted by RRF score descending

Expected behavior:
- Input: List of dicts mapping system_name → List[Dict] (each dict has chunk_id + metadata)
- Output: List[Dict] with chunk_id, metadata, rrf_score, sources (which systems found it)
- Chunks in multiple systems accumulate scores (overlap boost)
- Deduplicated by chunk_id
- Sorted by rrf_score descending
  </behavior>
  <implementation>
Class: RRFFusion
- fuse(self, results: Dict[str, List[Dict]], k: int = 60) -> List[Dict]

Algorithm:
1. Create score accumulator: defaultdict(float)
2. Create chunk metadata dict: Dict[chunk_id, metadata]
3. Create source tracker: Dict[chunk_id, Set[system_name]]
4. For each system and its ranked results:
   - For position, chunk in enumerate(results, start=1):
     - scores[chunk_id] += 1 / (k + position)
     - metadata[chunk_id] = chunk (store first occurrence)
     - sources[chunk_id].add(system_name)
5. Build output list: [{chunk_id, ...metadata, rrf_score, sources}]
6. Sort by rrf_score descending
7. Return sorted list

Constants: k=60 (can be overridden via parameter)

Handle edge cases: empty results, single system, missing chunk_id (skip/log warning)
  </implementation>
</feature>
